# Historical audit material

This directory contains historical reconciliation evidence and working
reports. Its contents are not architecture specifications and do not
participate in normative precedence.

Accepted outcomes must be recorded in the current
[architecture](../../architecture/README.md), an accepted ADR, or the
applicable [decision-status register](../../decisions/README.md) before
implementation relies on them.

The reports retain paths and terminology from the repository state they
examined. Those references may no longer resolve after later reorganizations.

Version control tracks this directory completely for historical provenance.
Tracking a report does not give it normative authority.
